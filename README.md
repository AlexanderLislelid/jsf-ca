## Getting Started

### Prerequisites

- Node.js (version)
- npm / yarn / pnpm

### Installation

```bash
git clone <repository-url>
cd <project-directory>
npm install
```

### Environment Variables

Create a `.env.local` file in the root directory and add any required variables:

```bash

```

### Running the Development Server

```bash
npm run dev
```
